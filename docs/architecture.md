# Employer Home — architecture and design regions

- Role: Employer / HR manager; Home at `/`
- Shared chrome: Sidebar, Header, EmployerShell
- At a Glance: MetricCard ×3 and one independent daily/weekly/monthly control

- Things to do: TaskList and demo task actions
- Employee Participation: chart, series legend, second independent period control
- Care Access: aggregated status/rates
- Quick Actions: shared Button and in-app route links
- Growth Plan label, organization switcher, Inbox, Overview, Workspace, usage module, General

- Data: types -> typed fixture -> service -> server route -> client view
- Ownership: layout in components/layout; dashboard areas in features/dashboard
- Privacy: employer sees aggregated anonymized counts only
- Scope: destination pages are placeholders pending their separate Figma designs

- Assets: original logo, avatar, icon exports are added during Figma polish
